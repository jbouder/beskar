# Beskar

**Beskar** is the design system for my vibe projects. It is a
[shadcn](https://ui.shadcn.com/) component registry: every component is a small
source file you copy into your own app with the `shadcn` CLI. You own the code.

- **Style:** shadcn `base-lyra` on [Base UI](https://base-ui.com)
- **Fonts:** Oxanium for UI and headings, JetBrains Mono for code
- **Icons:** Phosphor
- **Corners:** square

## Status

In place so far:

- The theme and the **Style Guide**: colors, typography, icons, and motion.
- 33 **Components**: the form basics (button, input, checkbox, switch, field,
  and more), the overlays and menus (dialog, sheet, popover, dropdown menu,
  select, combobox, command, and toasts), and the app pieces (sidebar, table,
  calendar, avatar, alert, progress, empty state, and toggles).
- The **Hooks** for theme preference and for the mobile breakpoint.

The AI skills are next.

## Installing

Add the registry to your app's `components.json`:

```json
{
  "registries": {
    "@beskar": "https://beskar.vibeproject.workers.dev/r/{name}.json"
  }
}
```

Then add items by name:

```sh
bunx shadcn add @beskar/theme
bunx shadcn add @beskar/button
```

`@beskar/theme` writes the tokens into your stylesheet and installs the fonts.
It is safe to run again after an update. Every component pulls in the theme
and `utils` on its own, so adding a component is enough.
